\section{Herencia}
La herencia permite crear una clase nueva basada en otra existente, reutilizando atributos y métodos.

\subsection{Ejemplo}
\begin{lstlisting}
class Animal:
    def hablar(self):
        print("Ladridos")

class Perro(Animal):
    def hablar(self):
        print("Guau Guau")

Perro().hablar()
\end{lstlisting}

\section{Clases Abstractas}
Las clases abstractas definen métodos que deben implementarse en las clases hijas, sirviendo como modelo base.

\subsection{Ejemplo}
\begin{lstlisting}
from abc import ABC, abstractmethod

class Figura(ABC):
    @abstractmethod
    def area(self):
        pass

class Cuadrado(Figura):
    def __init__(self, lado):
        self.lado = lado
    def area(self):
        return self.lado ** 2

print(Cuadrado(4).area())
\end{lstlisting}

\section{Polimorfismo}
El polimorfismo permite que distintos objetos respondan de forma diferente al mismo método.

\subsection{Ejemplo}
\begin{lstlisting}
def hacer_hablar(animal):
    animal.hablar()

hacer_hablar(Perro())
hacer_hablar(Animal())
\end{lstlisting}

\section{Interfaces}
Una interfaz define un conjunto de métodos que deben ser implementados por las clases que la hereden.

\subsection{Ejemplo}
\begin{lstlisting}
from abc import ABC, abstractmethod

class Vehiculo(ABC):
    @abstractmethod
    def mover(self):
        pass

class Coche(Vehiculo):
    def mover(self):
        print("El coche se mueve")

Coche().mover()
\end{lstlisting}

\section{Method Resolution Order (MRO)}
El MRO define el orden en que Python busca los métodos en una jerarquía de clases múltiples.

\subsection{Ejemplo}
\begin{lstlisting}
class A:
    def saludar(self): print("A")

class B(A):
    def saludar(self): print("B")

class C(A):
    def saludar(self): print("C")

class D(B, C): pass

print(D.__mro__)
D().saludar()
\end{lstlisting}
